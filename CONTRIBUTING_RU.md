# Участие в проекте

[English](CONTRIBUTING.md) | **Русский**

Спасибо за желание помочь проекту. Наиболее полезны отчёты о совместимости
конкретных USB Wi-Fi адаптеров, исправления драйверов и воспроизводимые
результаты сборки.

## Отчёт об адаптере

Укажите:

- точное название адаптера и аппаратную ревизию;
- USB VID:PID;
- чипсет, если он достоверно известен;
- диапазон 2,4/5 ГГц;
- появился ли новый интерфейс;
- прошли ли обычное сканирование, monitor mode и injection;
- тип OTG-переходника и наличие внешнего питания;
- релиз проекта и SHA-256 использованных файлов.

Не публикуйте серийный номер телефона, IMEI, MAC-адреса, пароли, capture-файлы
из чужих сетей, приватные ключи и дампы разделов.

## Изменения исходников

Pull request должен:

1. иметь понятное описание проблемы и затронутого драйвера;
2. сохранять исходные copyright/license headers;
3. не добавлять проприетарные APK, OEM boot images или пользовательские дампы;
4. перечислять выполненные host-side проверки;
5. обновлять манифесты и документацию, если меняются артефакты;
6. не включать автоматическую прошивку или доступ к телефону в build scripts.

Для изменений callback-функций при включённом CFI приложите подтверждение
совпадения фактических типов определения и точки регистрации callback.

## Новая прошивка

Поддержка другой версии Realme UI требует отдельного варианта. Нельзя просто
переименовать C.13-пакет: нужно повторно проверить kernel commit, конфигурацию,
ABI vendor-модулей, сертификат, boot metadata и полный цикл сборки.
